读图说明与实现边界

树节点表示原文的 AST/CST 字节区间，BPE 合并只改变下方 token 划分，不修改这棵源树。图中高亮的是本步实际合并或读取的范围。训练轮次作用于全部四条语料；图中只画第一条公式。

Training 指分词器学习词表，不是 Transformer 的梯度训练。顺序为：解析源区间 → 从单字节开始 → 统计合法相邻 pair → 选最高频 pair → 合并并重计数。每次重计数都可能改变下一轮的优先级。

Encoding 使用已经学好的 merge rank；较小 rank 优先，同 rank 时左边的位置优先。不存在的 pair 不进入候选队列，合并前还会检查邻接关系、版本和区间合法性。

Decoding 依次取出 vocab[id] 的字节，拼接后统一 UTF-8 解码。单个 token 可能只包含一个多字节字符的一部分，所以必须先拼接字节。

本演示使用底层 256 个单字节 ID，学到 16 个新 token 后在容量 272 处停止。仓库当前主配置的对外基础表为 98 个 ASCII/空白字符，紧凑映射与 PAD/EOS/BOS 是另外一层；本图不把内部 ID 当作最终模型 ID。

小语料用于解释算法，并非仓库 212/636 条正式训练的结果。支持的算术语法使用表达式 AST，其他语法保留绑定 CST；图示不声称是通用数学语义树。
