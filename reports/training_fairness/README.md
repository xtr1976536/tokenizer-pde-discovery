# PINN路径及两规模训练准入公平性核查

2026-11-04。核查当前公开仓库实际主入口scripts/pde_experiment.py，不凭历史辅助函数的存在推断运行行为。

## PINN

主入口仅调用train_round1、study3_search.search及只读load_existing。search执行生成、共同RewardEvaluator中的最小二乘数值reward、Top10、SFT和被动探针，没有调用run_pinn或train_PINN。原版PINN源码/辅助函数保留，不在本次正式入口中执行。已有MLP作为固定数值代理，用于导数及评分；这不同于最终以PDE残差继续优化的PINN阶段。当前只能报告结构发现，不能报告已完成最终系数/PINN恢复。

## 全量输入审计

不是仅检查之前8条小试。直接按正式入口相同逻辑编码两个规模的全部增强输入，使用真实作者MyDataSet/padding_batch遍历每一训练批次，核对源ID、样本数、特殊token、词表范围、目标token计数、完整长度和Hard解码还原。

Hard词表训练manifest的语料摘要等于该组所有未增强源公式统一渲染文本的摘要，636组使用636条，每源一次，不用目标或额外隐藏文本。EqGPT为固定57ID字典，不涉及重新训练分词器；每条公式GRE完整可表示。

两个规模下四模型接收相同source_id/augmentation_index顺序；同一语料组没有任何模型独享的公式、排除项、UNK替换或截断。正式run的chosen=rows，仅smoke显式选8源样本；不能把smoke当作全量训练。

## 公平性范围

同一组四模型使用同一源公式、32次增强、六层主干、相同epoch/batch/Adam/clip、相同MLP和搜索候选预算及共同评分选择。词表内容及大小不同会自然改变参数量与序列长度；等epoch不等预测token或FLOPs。SAT仅EqGPT启用是用户明确保留的差异，不能宣称比较只含分词因素。

原212的已知重复和3条作者数值token语义问题仍两边保留；本审计证明训练准入，不证明这些数值语义已修复。两组Hard独立学词表，语料规模比较包含词表学习变化。
